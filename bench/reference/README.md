# References kept

Meshes the bench compares with but does not make: they are tracked.

## handmade/

The meshes modelled by hand on the human bodies of Blender's Essentials library (CC0; see
[CREDITS.md](../../CREDITS.md)): the base level of their Multires, 10,590 faces each. The bench
measures them as `handmade`, against their own number of quads, and runs openclare at that
number as `openclare-as-handmade`.
